# Portfolio — Maia Cheb Terrab

Web del portfolio. Se publica en https://maiucheb-oss.github.io/portfolio/

- `index.html` — la página, autocontenida (CSS y JS inline, fuentes en `assets/fonts/`).
- `assets/<proyecto>/` — las piezas optimizadas para web. Los originales en resolución
  máxima están fuera del repo, en `Portfolio 2026/Behance/`.
- `archivos editables/build_web.py` — regenera `index.html` a partir de
  `web_assets.json`. Se corre con `python3 "archivos editables/build_web.py"`.

Key visual tomado del CV verde: Geist Mono, verde `#bbf0a5`, tinta `#111`.
